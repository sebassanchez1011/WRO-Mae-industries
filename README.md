# 🌿 Voces de la Tierra

**Portal interactivo de lenguas y culturas indígenas de Costa Rica**

Una aplicación web progresiva (PWA) para aprender y preservar las lenguas, comidas, medicina, arte y cosmovisión de los 7 pueblos indígenas de Costa Rica.

## Funcionalidades

| Funcionalidad | Descripción |
|---|---|
| 🎤 **Preguntas por voz** | Habla o escribe preguntas y recibe respuestas con audio (como Siri) |
| 🗣️ **Traductor** | Traduce palabras entre español y las 7 lenguas indígenas |
| 🌽 **Alimentación** | Platos típicos, ingredientes y comida ceremonial |
| 🌿 **Medicina** | Plantas medicinales y prácticas de sanación tradicional |
| 🎨 **Arte** | Artesanía, símbolos, técnicas ancestrales y tintes naturales |
| 🌎 **Cosmovisión** | Historia, ceremonias, mitología y organización social |
| 📚 **Glosario** | Buscador completo de palabras por lengua y categoría |
| 📱 **Offline** | Funciona sin internet gracias al Service Worker |
| 🔊 **Voz fluida** | Text-to-Speech con pronunciación natural en español |

## Lenguas incluidas

| Lengua | Pueblo | Hablantes | Región |
|---|---|---|---|
| Bribri | Bribri | ~7,000 | Talamanca |
| Cabécar | Cabécar | ~3,000 | Chirripó |
| Ngäbere | Ngäbe | ~5,000 | Puntarenas Sur |
| Maleku | Maleku | ~1,000 | Guatuso |
| Boruca | Boruca | ~150 | Boruca |
| Térraba | Térraba | ~30 | Térraba |
| Huetar | Huetar | Extinta | Valle Central |

## Tecnologías

- HTML5 + CSS3 + JavaScript (sin frameworks)
- Web Speech API (reconocimiento de voz y síntesis)
- Service Worker (offline-first)
- Manifest.json (PWA instalable)
- GitHub Pages (hosting)

## Despliegue

1. Subir todos los archivos a `https://github.com/sebassanchez1011/WRO-Mae-industries`
2. Activar GitHub Pages en **Settings → Pages**: Branch `main`, folder `/ (root)`
3. La web estará disponible en `https://sebassanchez1011.github.io/WRO-Mae-industries/`

## Créditos

Datos basados en fuentes académicas (CONARE, Universidad de Costa Rica, UNESCO) y el trabajo de revitalización lingüística de las comunidades indígenas de Costa Rica.
